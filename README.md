This repository is organized into different levels, where each folder focuses on a specific HTML concept with practical examples.

## 🚀 How to Use

1. Clone the repository

```bash
git clone https://github.com/rehuuu01/Html-Detailed.git
```

2. Open the project in **Visual Studio Code**

3. Open any HTML file in your browser using **Live Server**.

4. Practice and modify the examples.
